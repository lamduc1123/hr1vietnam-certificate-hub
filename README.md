# 🎓 HR1Vietnam x HUTECH - Certificate Hub (Cổng Cấp & Tra Cứu Chứng Nhận Company Tour)

Hệ thống ứng dụng Web tự phục vụ (Self-service Hub) dành cho sinh viên **HUTECH** tra cứu và tải Chứng nhận hoàn thành Company Tour tại **HR1Vietnam**.

---

## 🌟 Các Tính Năng Nổi Bật (Highlights)

### 1. Phân hệ Tra cứu & Nhận Bằng cho Sinh Viên:
- **Tra cứu thông minh**: Sinh viên nhập đúng Mã Số Sinh Viên (MSSV) hoặc Họ Tên.
- **Xem trước bản cứng (Live Certificate Preview)**: Khung bằng chuẩn Diploma với viền dập nổi hoạ tiết ánh kim, logo thương hiệu HR1Vietnam & HUTECH.
- **Tải file PDF chuẩn in ấn / CV**: Tự động render file PDF định dạng A4 Landscape nét cao.
- **Tải file ảnh PNG**: Chuẩn để lưu trong điện thoại hoặc đăng mạng xã hội.
- **Chia sẻ LinkedIn 1-Click**: Tích hợp sẵn nút mở LinkedIn kèm mẫu câu đăng bài chuẩn Branding gắn thẻ HR1Vietnam.

### 2. Phân hệ Quản Lý HR (HR Admin Panel):
- **Import file Excel / CSV**: HR chỉ cần nạp file danh sách điểm danh (MSSV, Họ tên, Lớp, Khoa, Ngày tham gia).
- **Thêm/Sửa/Xóa sinh viên linh hoạt**: Quản lý trực tiếp trên giao diện.
- **Tải File Excel Mẫu**: Tải file `.csv` mẫu để HR điền thông tin đợt Company Tour mới.

### 3. Phân hệ Xác Minh Tính Hợp Lệ (QR Code Verification):
- Mỗi bằng được gắn 1 **Mã ID duy nhất** & **Mã QR code**.
- Khi quét mã QR hoặc nhập ID trên trang Xác minh, hệ thống đối soát dữ liệu và trả về kết quả *"Chứng nhận HỢP LỆ"* chính chủ từ HR1Vietnam.
